# Sistema de Cadastro de Alunos (Python + Tkinter + JSON)

## Objetivo
Aplicação desktop para cadastro de alunos com interface gráfica, persistência em JSON e funcionalidades de busca, ordenação e edição.

## Recursos
- Interface gráfica com Tkinter/ttk
- CRUD completo (adicionar, editar, remover)
- Busca em tempo real por nome
- Ordenação por coluna
- Persistência em arquivo JSON
- Mensagens amigáveis e confirmação de exclusão

## Tecnologias
- Python 3
- Tkinter
- JSON

## Como executar
```bash
python cadastro_gui.py
